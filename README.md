useParams 
он используется когда нам нужно отображать динамический контент по заданному значению получакм это значения 

useNavigate
используется когда нам нужно перенаправить куда-нибуть пользователя при какомто действии 

protected route
это механизм при котором если мы обернули контент то его можно сделать чтобы он отображался только для пользователей которые авторизованы, там идет проверка
